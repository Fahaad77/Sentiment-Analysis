# Sentiment Analysis Research Presentation

Browser-based presentation for GitHub Pages.

Presenter: Najla Saad Almotiri  
Student ID: 202604229

## Use

Open `index.html` in a browser, or serve this folder as the root of a GitHub Pages site.

Keyboard controls:

- Right arrow, Page Down, or Space: next slide
- Left arrow, Page Up, or Backspace: previous slide
- N: show or hide speaker notes
- Home: first slide
- End: last slide

## Files

- `index.html`: slide content and speaker notes
- `styles.css`: green/gold theme and responsive layout
- `script.js`: navigation, progress, and notes behavior
- `assets/`: reused visuals extracted from the supplied presentation/source files
